# ArtCrew ARMADA — Atelier Web Platform

Luxury atelier for upcycled art, fine jewelry, ancient craft, and sustainable haute craftsmanship.

---

## 🏛️ About ArtCrew ARMADA

ArtCrew ARMADA is an experiential web platform designed to present the convergence of ancient metallurgical arts (lost-wax casting, Byzantine chainmaille, Mokume-gane) and circular haute craftsmanship (salvaged maritime steel, aeronautical titanium, and vintage horological components).

### Key Features
- **Trilingual Localization**: Instant client-side switching between Thai, English, and French.
- **Interactive Atelier Navigation**: Seamless drawer navigation and quick-access top bar with scroll-spy synchronization.
- **Curated Collections & Catalog**: 7 distinct categories (Jewelry, Accessories, Decorations, Upcycling, Textile, Art & Culture, and Course Learning) with a detailed modal inspection view.
- **Cart & Bespoke Orders**: Shopping bag drawer with quantity management and direct bespoke consultation forms.
- **Workshops & Masterclasses**: Hands-on masterclass booking system.
- **Circularity & Awareness**: Real-time impact indicators (metals diverted, carbon offset).

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or 20+
- npm or yarn

### Installation
```bash
# Clone the repository
git clone <repository-url>
cd artcrew-armada

# Install dependencies
npm install
```

### Development
```bash
npm run dev
```
The application will be accessible at `http://localhost:3000`.

### Production Build
```bash
npm run build
npm run preview
```

## 🛠️ Tech Stack
- **Framework**: React 19 + TypeScript

- **Styling**: Tailwind CSS v4
- **Motion**: `motion/react`
- **Icons**: Lucide React
